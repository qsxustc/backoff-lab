# Backoff Lab v1.0.0 — See every retry

The first stable release of Backoff Lab: an interactive microscope for retry storms, backoff, and jitter. Compare five retry policies against one recovering service, then inspect the experience of an individual client.

**[Try the live demo](https://qsxustc.github.io/backoff-lab/)** · [Getting started](https://github.com/qsxustc/backoff-lab#try-it-locally) · [中文说明](https://github.com/qsxustc/backoff-lab/blob/v1.0.0/README.zh-CN.md)

## What you can do

- Compare fixed delay, exponential backoff, full jitter, equal jitter, and decorrelated jitter.
- Replay client timelines and inspect every attempt, response, outcome, and actual wait.
- Tune client count, outage duration, concurrency, response time, retry delays, attempt budgets, deadlines, and Retry-After.
- Reproduce experiments with a seed and a shareable scenario URL or JSON file.
- Export all attempts as CSV or download a standalone HTML report.
- Run the same deterministic engine from the browser, the Node.js CLI, or an ES module.

The app has no third-party runtime dependencies, analytics, API keys, or account requirement. The README includes a recorded walkthrough; the repository includes English and Chinese getting-started guides and a documented simulation model.

## A quick experiment

Open the demo and choose **Recovery burst**. With 120 clients, a 1.5-second outage, 12 concurrent server slots, and seed **42**:

| Policy | Clients completed | Total attempts |
| --- | ---: | ---: |
| Exponential backoff | 48 / 120 | 888 |
| Full jitter | 120 / 120 | 689 |

These are results for the included scenario, not a universal ranking. Capacity means concurrent accepted requests. The model uses a finite client burst and fixed response times; p95 includes successful clients only. See the [model and its boundaries](https://github.com/qsxustc/backoff-lab/blob/v1.0.0/docs/model.md) before interpreting the results.

## Run locally

Requires **Node.js 20 or newer**. No `npm install` step is needed.

```sh
git clone --branch v1.0.0 https://github.com/qsxustc/backoff-lab.git
cd backoff-lab
npm run dev
```

Open [http://127.0.0.1:4173](http://127.0.0.1:4173). Try the CLI with:

```sh
node bin/backoff-lab.js --scenario examples/recovery.json --policy exponential --policy full
```
